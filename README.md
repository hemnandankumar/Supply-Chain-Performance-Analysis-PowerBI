Supply-chain Performance Analysis Dashboard
Project Overview
This project analyzes sales data using Power BI to uncover trends, track performance, and generate actionable business insights.

Business Objective
To help stakeholders:
- Monitor sales performance
- Identify top-performing products and regions
- Improve profitability through data-driven decisions

Tools & Technologies
- Power BI
- Excel
- Power Query
- DAX (Data Analysis Expressions)
  
Key KPIs
- Total Sales
- Total Profit
- Profit Margin
- Sales Growth
- Top Products
- Region-wise Performance

Key Insights
- West region contributes the highest sales
- High discounts reduce profitability
- Sales peak observed in Q3
- Top 20% products generate majority revenue

 Business Impact
- Helps optimize pricing strategy
- Identifies high-performing areas
- Supports strategic decision-making

 Project Structure
- Data files
- Power BI dashboard
- Business documents
- Insights report

How to Use
1. Download the .pbix file
2. Open in Power BI Desktop
3. Interact with filters and visuals
